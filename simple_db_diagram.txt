TABLE RELATIONSHIPS
====================================
shiprag_auth.users  1:N  shiprag_auth.api_keys
shiprag_auth.users  1:N  shiprag_chunks.projects
shiprag_chunks.projects 1:N  shiprag_chunks.chunks

VECTOR SEARCH CAPABILITY
====================================
The chunks table stores:
- Text content
- 1536-dimensional vector embeddings
- Full-text search index (content_tsv)
- Hybrid search function (vector + keyword)

====================================

createdb -U postgres shiprag_chunks
createuser -U postgres shiprag
# Set password for shiprag user when prompted
